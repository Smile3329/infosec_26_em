Notes

The card fields use the cc- family: cc-name, cc-number, cc-csc, and the expiry split into cc-exp-month and cc-exp-year selects. A filler must match its stored expiry against option values (1 to 12, four-digit years), not the visible labels.

cc-type is a select with the vendor-ish values visa, mc, amex and discover, so brand detection from the number is the only reliable way to pick one. See 1Password's developer guide for checkout guidance.
